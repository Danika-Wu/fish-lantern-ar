# Fish Lantern AR

An image-tracked WebAR experience exploring illness stigma through a physical fish lantern.

- `index.html`: live camera and image-tracked AR
- `preview.html`: non-tracked effect preview
- `targets/fish-core.mind`: compiled image-recognition target

Open the published GitHub Pages site in Safari or another modern mobile browser, allow camera access, and point the rear camera at the fish lantern.
